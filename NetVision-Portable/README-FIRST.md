# NetVision Portable

## iOS

Open this file:

```text
NetVision-iOS-Standalone.html
```

It contains the app, styling, database, and subtitle data in one file.

If you see `Standalone iOS build` in the bottom-right corner, you opened the correct file.

## macOS / Windows

Open:

```text
tv-prototype/index.html
```

or use the platform launcher in `tv-prototype`.

## Videos

For local copyright-free videos, put the MP4 files in:

```text
tv-prototype/media/
```

See:

```text
tv-prototype/VIDEO_SOURCES.md
```
